# TaskFlow – Student Task Management System

## Description
A responsive front-end web application that helps students organize school tasks, due dates, and priorities.

## Objectives
- Organize academic tasks in one place.
- Add, edit, delete, and complete tasks.
- Search and filter tasks.
- Save task data in the browser.

## Features
- Dashboard with task statistics and progress.
- Add, edit, delete, and complete tasks.
- Search by task title or subject.
- Filter by status and priority.
- Upcoming schedule sorted by due date.
- Form validation and Local Storage.
- Responsive desktop, tablet, and mobile layout.

## Technologies
HTML5, CSS3, JavaScript, Local Storage, Visual Studio Code.

## How to Run
1. Extract the project folder.
2. Open it in Visual Studio Code.
3. Open `index.html` using a browser or Live Server.
4. Add tasks using the New Task button.
